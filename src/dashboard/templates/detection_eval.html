⚙️ Justification des hyperparamètres

Z-Score — window=30, seuils z=2/3

Une fenêtre de 30 points offre un équilibre entre réactivité (détection rapide de dérives) et stabilité statistique (réduction du bruit). Le seuil |z| ≥ 2 déclenche une alerte WARNING (probabilité ≈ 5 % sous loi normale), et |z| ≥ 3 déclenche CRITICAL (probabilité ≈ 0.3 %). Ces seuils sont des standards industriels reconnus (règle empirique 68-95-99.7).

IQR — window=30, k=1.5/3.0

Le multiplicateur k=1.5 (WARNING) correspond à la règle de Tukey standard pour les boîtes à moustaches, identifiant les valeurs atypiques légères. k=3.0 (CRITICAL) cible les valeurs extrêmes. L'IQR est robuste aux valeurs aberrantes (contrairement à la moyenne), ce qui le rend complémentaire au Z-Score.

Isolation Forest — window=100, contamination=0.05

La fenêtre de 100 points garantit suffisamment de données pour entraîner les 100 arbres de décision de manière stable. Le paramètre contamination=0.05 (5 % d'anomalies attendues) correspond au taux réel observé dans les données IoT industrielles. La valeur random_state=42 assure la reproductibilité des résultats. Le réentraînement toutes les 20 lectures (retrain_every=20) maintient l'adaptation au contexte courant sans surcharge CPU.

Règles métier — seuils fixes par capteur

Les seuils sont définis par expertise métier (normes eau potable WHO/OMS) : température 20–30 °C normal, pH 6.5–8.5 acceptable, turbidité < 5 NTU sûre. Cette approche garantit une précision maximale pour les anomalies connues mais ne détecte pas les dérives progressives ni les patterns inhabituels. Elle sert de référence de base pour comparer les méthodes statistiques.

💡 Interprétation et recommandations

  • Règles métier : haute précision sur les violations de seuils explicites, mais aveugle aux anomalies contextuelles et dérives.
  • Z-Score : efficace sur les signaux stationnaires. Sensible aux changements de régime qui peuvent fausser la moyenne.
  • IQR : plus robuste que le Z-Score face aux valeurs extrêmes persistantes. Idéal en présence de distributions asymétriques.
  • Isolation Forest : seul détecteur non-supervisé capable d'apprendre des patterns complexes. Nécessite {{ warmup_readings }} lectures de warmup pour converger.

Le moteur utilise une stratégie worst-case : le niveau le plus sévère parmi les 5 détecteurs est retenu (Rules + ZScore + IQR + IF univarié + IF multivarié), maximisant le rappel au prix d'un léger surcoût en faux positifs.
